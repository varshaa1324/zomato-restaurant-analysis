## Zomato Bangalore Restaurant Analysis

## About
Analyzed 7000+ Bangalore restaurants from Zomato dataset 
to find insights on cuisines, areas, online ordering and costs.

## Tools Used
- Python
- Pandas
- Jupyter Notebook
- Tableau

## Steps
1. Downloaded dataset from Kaggle
2. Cleaned data using Pandas
3. Handled missing values using median
4. Performed EDA to find insights
5. Built interactive Tableau dashboard

## Key Findings & Recommendations

### 1. North Indian cuisine dominates with 421 restaurants
**Solution:** Restaurants serving South Indian or fusion cuisines 
can target underserved areas to reduce competition

### 2. 52% restaurants accept online orders
**Solution:** Remaining 48% should adopt online ordering 
to capture digital customers especially post COVID

### 3. Byg Brewski is most reviewed with 15K+ ratings
**Solution:** Other restaurants should study Byg Brewski's 
customer engagement strategy and replicate it

### 4. Fine Dining costs ₹3000 for two people
**Solution:** Mid-range restaurants (₹500-₹1000) have huge 
opportunity as most Bangalore customers prefer affordable dining

### 5. Byresandra area has most restaurants
**Solution:** Areas like Banashankari and Kalyan Nagar have 
fewer restaurants — good opportunity for new restaurant owners
